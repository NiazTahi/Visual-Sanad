# Visual Sanad

Code for the MusIML@NeurIPS 2026 paper:

**Visual Sanad: Auditing Vision--Language Models for False Acceptance of Qur'anic Citations**

## Contents

- `scripts/`: inference, scoring, statistical tests, and plotting utilities.
- `prompts/`: prompt templates used for model evaluation.

## Setup

```bash
pip install -r requirements.txt
```

API-based scripts read credentials from environment variables or local key files. Do not commit private credentials.
